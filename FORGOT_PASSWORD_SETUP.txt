FORGOT PASSWORD EMAIL SETUP
===========================

The forgot-password flow now sends a 6-digit code by Gmail SMTP, verifies the
code, and only then allows a password reset. Codes expire after 10 minutes and
are limited to five verification attempts.

1. Database migration
   Open phpMyAdmin, select directpath_db, then import/run:
   config/password_reset_migration.sql

2. Install PHPMailer
   Open a terminal in the directpath project directory and run:
       composer install
   Ensure PHP's OpenSSL extension is enabled.

3. Configure Gmail SMTP
   In config/config.php, set:
       SMTP_USERNAME  = your Gmail address
       SMTP_PASSWORD  = a Google App Password (not your normal Gmail password)
       SMTP_FROM_EMAIL = the same Gmail address
   Keep SMTP_HOST=smtp.gmail.com, SMTP_PORT=587, SMTP_SECURE=tls.
   Create an App Password from the Google Account security settings after
   enabling 2-Step Verification. If the Gmail account is managed by an
   organization, its administrator may disable App Passwords.

4. Test
   Visit index.php -> Forgot Password? -> enter a registered account email ->
   retrieve the 6-digit code from Gmail -> verify -> set a new password -> sign in.

Important:
- This is not fully operational until the migration, Composer dependency, and
  real SMTP credentials are configured in your local/server environment.
- Do not publish or commit real SMTP credentials. For deployment, use environment
  variables or a secret manager rather than storing secrets in source control.
- Ensure the server can make outbound SMTP connections to smtp.gmail.com:587.
